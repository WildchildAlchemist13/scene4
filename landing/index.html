The HBC Framework

Hook (0-15s) → Beat (15-90s) → Cliffhanger (90-120s). Every episode. Every time.

HOOK

Plunge into conflict/shock. No intros. Rule: If it fits a weather report, delete.

BEAT

Core action: 2-3 micro-scenes. Escalate stakes. Cut repeat info.

CLIFFHANGER

5 Types: Revelation/Danger/Emotional/Arrival/Decision. Make stopping hurt.
